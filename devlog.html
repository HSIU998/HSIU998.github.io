  21. 11/7
    拿掉沒進提示詞的那次撈取

    每輪多撈一次「最近脈絡」但提示詞不讀，這次撈取順便做到一件事——agent 原封不動重複自己前幾句時，回覆守衛靠它擋下重寫（正式環境 1,396 份回覆稿有 3 次，只拿掉的話這 3 次都擋不到） → 撈取拿掉，回聲比對改看對話視窗裡 agent 自己最近 3 則（本來就在眼前，不多撈），兩個開關一起開；重啟後 14 個服務全上，服務檢查 OK 254，九個 agent 開機都印兩行開著。每輪不再撈、擋下重複這兩條路要有對話才看得到，還沒在正式環境走過。

  23. 11/7
    身分快照不再把全名蓋成短名

    七個 agent 的身分快照從 3 月重建起一直帶短名，每次開機還原都把建構時的全名蓋回短名 → 還原時以建構時的全名為準，快照格式升一版、舊版自動遷移，短名只記一行警告；同一個短名在另一個核心還被拿來找一次性回填的標記檔，改了會讓那次回填重做，所以那半刻意不動。測試環境九份快照副本短名 7 → 0、固定回覆整輪請求和回覆 0 差；部署後九個 agent 開機都以全名還原、七個各一行警告，開機後一小時存的九份新快照是新版格式、全名 → 判定為已修。這次的警告被 log 監看當成「第一次出現的新字樣」各報一次，服務檢查的尺一開始把這些轉述也算進去，改成只數原本那行後 OK 266。

  24. 11/7
