世界樹

世界模擬引擎：從一顆種子開始，只定規則、不寫劇本，讓世界自己長出來；目的是讓因果的資料是真的。程式由 AI 撰寫，世界觀、規則、規格與驗收由我負責。先寫它現在跑得起來的；當初的設計說法哪些量出來不成立，收在下面的「自查」裡。

世界樹：世界模擬引擎

世界樹不只是共用層，它本身是一個世界模擬引擎：從一顆種子開始，讓能量照物理規則一層層生成地形、環境、族群和社會；每一個被模擬的個體都有唯一 ID、出生時決定的初始參數，和一段完整的生命歷程。程式約 3 萬行、100 多個檔（不含測試與備份）。

設計目標：因果之書的資料必須是真的。讓沒有預設性格、沒有記憶的空白代理，在模擬世界裡跑完完整的生命週期，再從它們實際做出的因果預測累積成大樣本統計。不用大型模型標註，也不寫死規則。規則創造世界，世界長出資料。

它現在跑得起來的：
  • 從一顆種子跑完整條生成管線；畫藍圖時一次生成 100 個世界拿來比較。
  • 能量總量守得住：54 個世界各跑 4,000 年，各層加總和 1 的最大差 2.2×10⁻¹⁶（靠每一步縮放回 1，細節在下面）。
  • 歷史只能寫一次：同一個世界 ID 已經存在就拒絕覆寫。
  • 觀察者介面確實唯讀。

項目設計目標自己量出來的
能量守恆總量固定為 1，自然守恆總量守得住，是每一步把總量縮放回 1 換來的；空間層本身不守恆，32² 的世界創世當下就是 1.50 倍
向量化加速改寫成陣列運算來加速整步 1.07～1.30 倍，串行再量 1.01 倍
物理引擎速率全部從物理常數推導，不加人工參數物理引擎（584 行）沒有被任何地方呼叫；它自己也不是純推導，檔內只有 4 個推導常數、101 個手寫浮點。管線實際跑的速率在別的檔，一樣是手寫表（world_genesis.py 366 個常數、world_state.py 的消耗表）
紀元參數表照「原典」設定各紀元的參數有 4 個標成「原典」的值，其實是推出來的
統一引擎七個步驟統一計算缺兩步，而且沒有任何地方呼叫它
量子編碼用量子電路影響元素之間的互斥方向全由手寫規則決定；量子電路實際改動的幅度，中位數只有 0.07%
空白代理跑一生空白代理在模擬世界跑完生命週期，產生因果預測模擬程式單獨跑時載不到代理核心；對世界事件的感知命中 0／1,005；「空白」代理其實帶著預設性格
因果之書人際層從日常 agent 的因果預測累積讀到的是三月的舊檔；八個角色算出來同一張臉
只讀觀察者只讀、追因果、跨世界比較介面確實唯讀；但讀到的那段能量歷史是常數，100 個世界全被判成「穩定」
角色一致性驗證分辨回覆是不是本人它量的是「屬不屬於這個世界」，不是身分：當初的 0.310 重現不出來，冒名的 50 則被判成真的 33 則

守恆不變量

能量總量固定為 1。模擬中的社會消耗的是各層的比例，消耗掉的能量最後回到最底層。2026-10-22 實測 54 個世界、各跑 4,000 年：各層加總和 1 的最大差 2.2×10⁻¹⁶。但這是程式每一步縮放回 1 換來的（程式碼最後一段）；空間層本身不守恆，見上表。

程式碼 · world_state.py
    # 從各層提取（不超過各層現有能量的 50%，防止單步過度提取）
    for tier, base_rate in tier_rates.items():
        rate    = base_rate * epoch_multiplier
        current = e.get(tier, 0.0)
        extract = min(rate * current, current * 0.5)
        e[tier]        = max(0.0, current - extract)
        total_extracted += extract

    # 守恆：提取的全部回到 tier9（乙太降格至元素態）
    e[9] = e.get(9, 0.0) + total_extracted

    # 守恆驗算（防禦性）
    total = sum(e.values())
    if abs(total - ether.total_ether) > 1e-9:
        scale = ether.total_ether / total
        e = {t: v * scale for t, v in e.items()}

舊版直接扣總量，跑久了能量趨近於零；改成循環模型之後總量守得住，但靠的是每步校正，還不是模型本身守恆。

向量化改寫

創世引擎的逐格迴圈改寫成 numpy 陣列運算，擴散那一段改用擴散方程近似原本的逐對計算，每格流量設上限。檔頭原本寫的加速倍數找不到量測紀錄；2026-10-22 實測整步只快 1.07～1.30 倍，10-23 串行再量是 1.01 倍，瓶頸卡在另一段沒改寫的計算。

程式碼 · genesis_vectorized.py
def _nb_sum(arr: np.ndarray) -> np.ndarray:
    """Sum of 4 neighbors. Zero at boundaries (no wrap)."""
    result = np.zeros_like(arr)
    result[1:, :] += arr[:-1, :]
    result[:-1, :] += arr[1:, :]
    result[:, 1:] += arr[:, :-1]
    result[:, :-1] += arr[:, 1:]
    return result

只讀的觀察者

世界跑完之後觀察者才能進來，只有讀歷史、追因果、讀各時期、跨世界比較四個介面，不能干涉。

程式碼 · world_observer.py
    def __init__(self, state: WorldState):
        if not state.is_finished:
            raise ValueError(
                f"觀察者原則：世界 [{state.world_id}] 尚未結束（狀態：{state.status.value}）。"
                f"只能觀察已完成或已滅亡的世界。"
            )
        # 觀察者持有一份引用，但永遠不修改它
        self._state = state

只定規則，不操控結果。介面守住了；它讀的資料沒接對，見上表。

焦點規則

四條規則從整段世界歷史挑出有份量的時刻，例如失衡分數單一時期跳動 ≥ 0.08、失衡等級第一次升高。挑出來的時刻再渲染成敘事文本。

程式碼 · focus_history.py
    EMOTIONAL_SURGE_DELTA     = 0.08   # 失衡分數單紀元跳動超過此值 → 情緒波動
    MAJOR_EVENT_LEVEL         = 2      # 失衡等級達到此值 → 重大事件
    FATE_TURNING_TIER7_DROP   = 0.008  # tier7 單紀元下降超過此值 → 命運轉折
    FATE_TURNING_RACE_SHIFT   = True   # 主導種族改變 → 命運轉折
    HISTORICAL_IMPACT_PERSIST = 2      # 影響延續超過此數量的後續紀元 → 歷史影響力

世界歷史是大綱，焦點時刻是主角。藍圖量到：挑出來的焦點時刻有 72% 其實是主角自己的人生事件，規則本身挑到的比想像中少。
